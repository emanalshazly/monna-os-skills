# Companion scope and alternatives

Review date: 2026-09-15. Two follow-on modules extend existing repository workflows. They are original public MIT contributions, not copies of a private commercial prompt or framework. There is no paid dependency or artificial output lock.

| Companion | Existing workflow | Narrow added artifact | Exclusion |
| --- | --- | --- | --- |
| audit-finding-closure-reviewer | ai-governance-framework produces audit work and tracked findings | Fixed-register closure matrix binding remediation observations to target revision and affected population | New audits, incident recovery, automated release gates and certification |
| arabic-release-change-reviewer | arabic-technical-translator produces Arabic technical copy | Old/current bilingual change ledger, minimal correction patch and regression packet | General translation, complete localization automation and visual RTL certification |

## Public alternatives inspected

- [invAIriant](https://github.com/mindicator/invAIriant/blob/main/skill/SKILL.md) includes architecture auditing and closure verification. Closure checking itself is therefore not a novel category. This companion targets supplied governance findings and heterogeneous remediation evidence rather than performing a code architecture audit.
- [Arabic UX Writing](https://github.com/itady74/ux-writing-arabic/blob/main/SKILL.md) covers Arabic interface wording. Arabic UX assistance is not a new category. This companion emphasizes attribution of release changes using paired old/current source and target snapshots.
- [Weblate checks](https://docs.weblate.org/en/latest/user/checks.html) already cover many mechanical localization checks, including placeholders and plural-related checks. This companion does not claim to replace them. Its proposed additional value is a review packet explaining changed product meaning and its Arabic correction.
- [Anthropic data validation](https://github.com/anthropics/knowledge-work-plugins/blob/main/data/skills/validate-data/SKILL.md) already addresses many data-analysis validity issues. A generic data verifier was excluded from this addition set.

These observations describe published documentation, not independently measured product performance. Search covered selected public GitHub sources and indexed marketplace results, not every commercial catalog or unindexed product. No global uniqueness, absence-of-competitor, demand, conversion or superiority claim is supported.

## Validation limits

The repository checks syntax, catalog consistency, local links, obvious secret patterns and configured lexical overlap. Lexical dissimilarity is not semantic differentiation. No same-input model comparison against a free alternative has been executed. The authored reference answers are not execution receipts. Both new Skills remain `draft`.
